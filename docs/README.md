## 📖 Documentation Standards

### Code Documentation
- Use JSDoc comments for functions
- Include examples in complex functions
- Document parameters and return types

### API Documentation
- All endpoints documented in [API.md](./API.md)
- Include request/response examples
- Document error cases

### Database Documentation
- Schema changes require migration documentation
- Update [DATABASE_SCHEMA.md](./DATABASE_SCHEMA.md) when adding tables
- Document relationships and indexes

## 🔄 Keeping Docs Updated

When making changes:

1. **Code Changes**: Update JSDoc comments
2. **API Changes**: Update [API.md](./API.md)
3. **Schema Changes**: Update [DATABASE_SCHEMA.md](./DATABASE_SCHEMA.md)
4. **Architecture Changes**: Update [ARCHITECTURE.md](../ARCHITECTURE.md)
